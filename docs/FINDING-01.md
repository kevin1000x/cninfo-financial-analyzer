# FINDING-01 — 年报可读性与当期经营业绩：一个零结果，以及它为什么只能读一半

**日期**：2026-09-03　|　**样本**：沪市主板 167 家公司 · 2024 年度报告
**一句话**：**在本样本上没有观察到年报可读性与当期 ROA 的关系**（r = 0.025，p = 0.75）。
但这个零结果**不能读成「可读性与业绩无关」** —— 因为本文所用的可读性指标
在公司之间几乎不变（变异系数 8.4%），它的区分能力本身没有被证成。

---

## 1. 问题

业绩差的公司，年报是不是写得更难读？

这是财务文本分析里的经典问题（「模糊化假说」）。本文不检验动机，只检验**关联**：
同一年度里，可读性指标与当期 ROA 之间有没有关系。

## 2. 数据

| 项 | 值 |
|---|---|
| 抽样框 | 巨潮资讯网股票清单里的**沪市主板**（600/601/603），**1,737 家** |
| 抽样 | 固定随机种子 `20260902`，抽 **200 家** |
| 年度 | **2024**（年报于 2025 年披露） |
| 自变量 | 年报 **MD&A 章节**的中文适配 Gunning-Fog 指数（`src/text_analyzer.py`） |
| 因变量 | **ROA**，经 AKShare 取得（`src/financial_data_sources.py`） |

**只用公开数据。** 年报 PDF 来自巨潮，财务指标来自 AKShare。PDF 不进版本控制，
留档的是 SHA-256 与字节数（`data/results/rvp_manifest.json`）。

### 2.1 样本是怎么从 200 变成 167 的

**每一步的损耗都记下来了，没有补抽。**

| 环节 | 结果 |
|---|---|
| 抽样 | 200 |
| 年报下载 | **171 成功**；25 家 `no_match`（已退市 / ST，无 2024 年报）；4 家 `ambiguous` |
| MD&A 抽取 | **167 成功**；3 家 `mda_fallback_fulltext`；1 家 `mda_too_short` |
| ROA | 187 成功 / 13 缺失（在 200 家上算） |
| **可用配对** | **167** |

**4 家 `ambiguous` 是同一种形态**：年报存在「（修订版）」与原版并存
（600422 / 600653 / 600984 / 603558）。脚本**拒绝替它们挑一份**，记为 `ambiguous` 并排除。
「修订版该不该进可读性样本」本身是个方法学问题，4 个观测不值得为它作答。

**3 家 `mda_fallback_fulltext` 是一道刻意加的判据抓到的**：
`extract_mda_section` 找不到章节时会 `return text`（返回整篇年报）。
那份全文轻松通过任何长度检查，**会被当成 MD&A 打分，而且事后无法察觉**。
判据是「MD&A 长度 > 全文 50% 即判失败」。这三家因此被排除，不是被静默计入。

## 3. 结果

```
n = 167
Pearson r(Fog, ROA) = +0.0249      p = 0.749
亏损组 (ROA < 0, n = 38)   Fog 均值 = 5.3111
盈利组 (n = 129)           Fog 均值 = 5.3120
两组差 = 0.0009
```

**两组均值差 0.0009，而 Fog 的标准差是 0.448。** 差异的标准误约 0.083，
观测到的差距只有 **0.01 个标准误** —— 这不是「不显著」，是几乎完美地为零。

⚠️ p 值用 `statistics.NormalDist` 的**正态近似**，不是 Student-t。
n = 167 时两者差别在小数点后第三位。这样做是为了不额外引入 SciPy 依赖，
在此写明而不是藏起来。

## 4. 🔴 为什么这个零结果只能读一半

**零结果有两种成因：真的没关系，或者尺子没在量东西。本研究分不开这两者。**

诊断：

| 诊断项 | 结果 | 含义 |
|---|---|---|
| Fog 的变异系数 | **8.4%**（均值 5.312，sd 0.448） | 公司之间几乎不变 |
| Fog vs MD&A 长度 | r = +0.139，p = 0.072 | **只有微弱关联，且不显著** |
| 「复杂词」的判定 | **退回了字符数阈值** | 见下 |

**最要紧的一条**：`TextAnalyzer` 启动时告警
`Common vocabulary not loaded, using character count threshold` ——
配置里声明的**常用词表在仓库里不存在**，于是「复杂词」退化成「字数超过阈值的词」。
中文里词的字数与它是否生僻**关系很弱**，因此这个 Fog 的构念效度未经证成。

⇒ **本文的正确读法**：
「在这套测量下，没有观察到关系」，**不是**「可读性与业绩无关」。
要把结论推进一步，先得让这把尺子在公司之间真的能分出高低。

## 5. 局限（逐条，不省）

1. **单年度、单板块。** 只有 2024 年、只有沪市主板。跨板块的年报模板不同，
   模板差异会以「可读性差异」的形式混进来，所以刻意没混板块 —— 代价是外部效度更窄。
2. **幸存者偏差。** 25 家 `no_match` 系统性地是已退市 / ST 公司，
   也就是**业绩最差的那一批**。它们掉出样本，**恰好会削弱本文要检验的那个关系**。
3. **可读性指标的构念效度未证成**（见 §4）。
4. **ROA 的口径不是本仓定义的**，来自 AKShare。**已实测确认**（§6）：
   分母是**平均总资产**，分子是含少数股东损益的**全部净利润**。
5. **AKShare 版本不一致**：本次实际运行 **1.18.94**，而 `requirements.txt` 钉的是
   **1.18.64**。照 README 装的人拿到的是被钉的那版。
   实际版本留档在 `data/results/rvp_roa_provenance.json`。
6. **关联不是因果。** 即便观察到关系，本设计也不能分辨方向或第三变量。
7. **本文没有检验模糊化假说的动机层面**，只检验关联。

## 6. 复核记录（做了哪些、做到什么程度）

**ROA 侧 3 家，两家逐位相同** —— 从年报版面手取净利润与总资产，独立算：

| 公司 | 版面依据 | 按期末总资产 | 按平均总资产 | AKShare |
|---|---|---:|---:|---:|
| 600007 中国国贸 | p91 / p92 | 10.2431% | 10.0168% | 10.0258% |
| 600020 中原高速 | p89 / p93 | 1.6870% | **1.7223%** | 1.7223% |
| 600190 锦州港（亏损） | p95 / p99 | −65.3971% | **−48.2639%** | −48.2639% |

⇒ **AKShare 的 ROA = 净利润（含少数股东损益） ÷ 平均总资产。**
600007 差的 0.009pp 是因为手取时用的是归母净利润。
**这条原先记为「口径未披露、未核」，现已由实测解决。**

**Fog 侧 4 家**：逐份读抽出的正文开头，确认取到的是「第三节 管理层讨论与分析」
正文而非目录页（600007 / 600020 / 600030 / 600035）。

⚠️ **效力限定**：以上核对**由本工具的作者执行**。
读数路径独立于抽取器（走 `pdfplumber` 原始版面文本，不经过 MD&A 抽取那一层），
**但执行者不独立**。这是**代码路径级**的独立，不是**执行者级**的独立。

## 8. 这次跑出来的、和结论无关但值得记的

做这项研究时，MD&A 抽取的失败率一度是 **64%**。量了两个总体才看清原因：

- 取错的候选：**15–363 字**（目录条目、风险提示里对本节的交叉引用）
- 取对的正文：**12,460–110,874 字**
- **中间是空的**

原判据只认点导引式目录（`...... 22`），而很多年报的目录是「节名 + 空格 + 页码」，
直接通过了检查。搜索循环本来就是对的（它会逐个匹配位置试），
是**校验器在第一个错的候选上就放行了**。加一条长度下限之后，
失败率从 64% 降到 2.3%，其中 600030 从 15 字变成 33,317 字。

⇒ 修复见 `src/pdf_parser.py` 的 `MIN_MDA_CANDIDATE_CHARS`。
